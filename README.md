# ذِكر | Dhker Web

موقع ويب عربي مستقل ومتكامل لخدمات ذِكر الأساسية، مع تطبيق Android منفصل.

## الخدمات الحالية
- قارئ نصي للقرآن بالرسم العثماني داخل الصفحة الرئيسية، مع حفظ الصفحات التي تُفتح في IndexedDB على الجهاز.
- صفحة مصحف مستقلة تعرض 604 صفحات مصوّرة من مشروع Mushaf Mauri، بصفحتين متقابلتين على الكمبيوتر وصفحة واحدة على الهاتف، مع حفظ موضع القراءة.
- مشغل تلاوات للسور مع اختيار القارئ (العفاسي، الحصري، المنشاوي، السديس، الشريم، عبدالباسط، العجمي، محمد أيوب، الحذيفي) عبر AlQuran Cloud CDN.
- مواقيت صلاة حسب المدينة عبر AlAdhan API، مع الاحتفاظ بآخر نتيجة لليوم في المتصفح.
- أذكار محلية من ملفات JSON، مع مراجع وعدّاد تقدم محفوظ على الجهاز.
- معاينة صوتي أذان من Wikimedia Commons؛ التسجيلان موثقان في تطبيق Android على أنهما CC0.
- تلاوات القرآن في الموقع تُبث عند الطلب ولا تُضمّن داخل ملفات الموقع أو تُخزّن تلقائياً دون اتصال.
- PWA مع Service Worker لتخزين ملفات الموقع وبيانات الأذكار والمدن.
- رابط إلى صفحة إصدارات Android الرسمية؛ لا يظهر رابط APK مباشر قبل نشر إصدار مبني وموقّع والتحقق منه على جهاز Android فعلي.

## حدود العمل دون اتصال
- يعمل هيكل الموقع والبيانات المحلية والأذكار بعد أول زيارة ناجحة وتخزين Service Worker.
- صفحات النص القرآني التي سبق فتحها تُحفظ محلياً في IndexedDB. صور المصحف المستقل تُخزّن مؤقتاً عند فتحها عبر Service Worker؛ لا تُنزّل جميع الصفحات تلقائياً، ولا تتاح دون اتصال إلا الصفحات التي سبق تحميلها بنجاح.
- مواقيت الصلاة تعرض آخر نتيجة محفوظة لليوم عند انقطاع الاتصال.
- تشغيل الأذان من الموقع يعتمد على مصدر خارجي وقد يتطلب الإنترنت؛ تطبيق Android يضم ملفات الصوت داخل APK.

## المصادر والتراخيص
- نص القرآن في القارئ النصي: AlQuran Cloud API، مع المحافظة على النص والإشارة إلى المصدر وشروط الخدمة: https://alquran.cloud/terms-and-conditions
- صور صفحات المصحف: مشروع Zizwar/mushaf-mauri، مجلد `_archive/assets/pages/hafsTajweed` على الفرع `expo55`. الصور تُحمّل مباشرة من GitHub Raw؛ راجع ترخيص المستودع وبيانات الأصول قبل إعادة التوزيع أو إعادة الاستضافة: https://github.com/Zizwar/mushaf-mauri
- تلاوات القرآن: AlQuran Cloud CDN، ويُستخدم البث وفق شروط الاستخدام غير التجاري/التعليمي المنشورة؛ لا تُعاد استضافة التسجيلات أو تضمينها في ملفات التطبيق دون مراجعة الحقوق: https://alquran.cloud/cdn
- مواقيت الصلاة: AlAdhan API.
- الأذان: Wikimedia Commons، ملفات Beautiful_adhan.ogg وAdhan.ogg؛ راجع صفحات الملف والترخيص قبل إعادة التوزيع.
- الأذكار والمراجع: بيانات محلية مشتركة مع مستودع تطبيق Dhker؛ ينبغي تدقيق الإسناد الحديثي علمياً قبل اعتماد مجموعة موسعة.

# ذِكر | Dhker Website

الموقع التعريفي الرسمي لتطبيق **ذِكر**.

- صفحة عربية باتجاه RTL ومتجاوبة مع الهاتف والكمبيوتر.
- مستودع الموقع عام ومنفصل عن مستودع التطبيق الخاص.
- زر Android يفتح صفحة إصدارات التطبيق الرسمية؛ لا يُعرض رابط APK مباشر قبل نشر إصدار فعلي واختباره.
- يوضّح الموقع بصدق الميزات المتاحة والميزات التي ما زالت قيد التطوير.

## النشر عبر GitHub Pages

من إعدادات المستودع افتح **Settings → Pages**، ثم اختر **Deploy from a branch**، والفرع **main** والمجلد **/(root)**، ثم اضغط **Save**.

## مستودع التطبيق

يُدار التطبيق في [TEaG3/Dhker](https://github.com/TEaG3/Dhker). تُنشر ملفات التثبيت من صفحة [الإصدارات](https://github.com/TEaG3/Dhker/releases) بعد نجاح البناء والاختبارات واعتماد إصدار.

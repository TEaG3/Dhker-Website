# ذِكر | Dhker Website

الموقع التعريفي الرسمي لتطبيق **ذِكر**.

## أساسيات الموقع
- صفحة عربية باتجاه RTL ومتجاوبة مع الهاتف والكمبيوتر.
- عنوان ووصف مناسبين للمتصفح ومشاركة الرابط (Open Graph).
- روابط واضحة إلى صفحة إصدارات Android الرسمية.
- توضيح الميزات المتاحة وما يزال قيد التطوير، دون الإيحاء بوجود APK غير منشور.
- قسم خصوصية يوضح أن إعدادات التطبيق والسبحة وموضع القراءة تُحفظ محلياً.

## حالة التطبيق
المستودع يحتوي حالياً على أساس تطبيق Flutter وواجهات أولية لمواقيت الصلاة والقرآن والأذكار. بعض الميزات لا تزال قيد التطوير، ولم يُتحقق بعد من جاهزية إصدار Android للتثبيت على جهاز فعلي.

**حالة Android:** التطبيق غير منشور للتنزيل حالياً. [تابع المستودع](https://github.com/TEaG3/Dhker) أو افتح [صفحة الإصدارات](https://github.com/TEaG3/Dhker/releases) لاحقاً؛ سيُضاف ملف APK بعد نجاح البناء والاختبارات والتحقق من الإصدار.

## النشر عبر GitHub Pages
من إعدادات المستودع افتح **Settings → Pages**، ثم اختر **Deploy from a branch**، والفرع **main** والمجلد **/(root)**، ثم اضغط **Save**.
